# CLASSICS NEOX

## Multi-Model Architecture Experiment

CLASSICS NEOX is a single Android application composed of six classic games. Each game is intentionally developed by a different AI model with independent architectural decisions. The application shell unifies navigation and packaging without homogenizing the internal game architectures.

| Model | Game | Current integration |
|---|---|---|
| Claude | Mahjong | `:mahjong` + `:core` |
| Grok | Sudoku | `app/src/main/java/com/classicsneox/sudoku/` |
| Gemini | Word Search | `app/src/main/java/com/classicsneox/wordsearch/` |
| ChatGPT / Logos | Lights Out | `app/src/main/java/com/classicsneox/lightsout/` |
| DeepSeek | Solitaire | `app/src/main/java/com/classicsneox/solitaire/` |
| Kimi | Crossword | `app/src/main/java/com/classicsneox/crossword/` |

## Current application structure

The repository contains three Gradle modules:

- `:app` — Android application and unified launcher.
- `:mahjong` — Claude's Android Mahjong module.
- `:core` — Claude's pure Kotlin/JVM Mahjong engine and tests.

The other games remain inside `:app` because that matches their actual repository structures. No artificial module boundary is introduced solely for architectural symmetry.

## Integrated games

### Grok — Sudoku

Immutable state + pure engine/generator/solver + reactive Compose presentation.

### Gemini — Word Search

MVI-style presentation layer over a pure Kotlin game domain, with an explicit integration entry point.

### DeepSeek — Solitaire

Independent domain engine, models, ViewModel and Compose presentation.

### Kimi — Crossword

Independent controller, core/generator, engine and Compose screen.

### Logos / ChatGPT — Lights Out

Independent deterministic puzzle engine and Compose presentation. New boards are generated by applying legal moves to a solved board, preserving solvability.

### Claude — Mahjong

Independent core engine/state/layout/scoring/persistence architecture plus an Android Compose module. The original core remains Kotlin/JVM and the Android layer consumes it through the module's public game entry point.

## Application shell

`MainActivity` provides the common launcher and navigation surface. It currently exposes all six integrated games:

1. Sudoku
2. Sopa de Letras
3. Solitario
4. Crucigrama · Kimi
5. Lights Out · Logos
6. Mahjong · Claude

Each game then renders its own presentation architecture.

## Integration principle

The project unifies the system boundary, not the internal architectures.

Each model keeps its own implementation choices. The integration layer is responsible for connecting those implementations to the common Android application without rewriting their internal engines merely to make them look alike.
